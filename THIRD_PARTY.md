# Third-party material

- The block/property registry is generated locally from pinned [PrismarineJS/minecraft-data](https://github.com/PrismarineJS/minecraft-data) using `scripts/prepare_registry.py`. The dataset is a setup input and is not included in this source distribution. See `data/editor-data-source.json` for attribution.
- Three.js, MIT: generated bundles include `static/three-LICENSE.txt`.
- Lucide icons, ISC: `static/lucide-LICENSE.txt`.
- nbtlib, NumPy and Litemapy are installed as dependencies, not vendored here.
- Minecraft client models, textures and language data are generated locally from an installed game client. They are not part of the MIT-licensed source distribution. Minecraft is a trademark of Mojang/Microsoft; this project is unofficial.
