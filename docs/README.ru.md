# Litematic Planner

Веб-редактор лайтматик и совместный сбор материалов. Быстрый запуск находится в основном README.
Подготовь ресурсы из своего Minecraft, собери фронтенд, создай иконки и запусти `python app.py`.

Редактор меняет блоки и сохраняет результат файлом. Сбор хранит участников, бронирования,
доставки и склад в SQLite. Секретная ссылка открывает доступ к конкретному сбору: не публикуй её.
Исходники редактора, HTTP API и 3D-просмотра описаны в документации для разработчиков.
