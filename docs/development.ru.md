# Разработка

Установите `requirements-dev.txt`, выполните `python scripts/prepare_registry.py`, затем `python -m unittest discover -s tests -v`. Тесты покрывают независимую проверку цикла чтения и записи NBT, отрицательные размеры, замены с сохранением свойств, расширение палитры и пользовательские теги. Данные создаются во временных файлах; рабочая база не нужна.

После изменений 3D-кода выполните `npm --prefix frontend ci` и `npm --prefix frontend run build`. Версии esbuild, Three.js и Lucide зафиксированы; собранные файлы сохраняют уведомления о лицензиях. После подготовки локальных ресурсов Minecraft команда `(cd frontend && node check-models.mjs)` проверяет геометрию. Помощник иконок доступен только на loopback, принимает лишь два сгенерированных файла и никуда их не загружает.

| Область | Исходники |
| --- | --- |
| Импорт, изменение и экспорт NBT | `schematic_editor.py` |
| HTTP, материалы и хранение | `app.py` |
| Интерфейс редактора | `static/editor.js`, `static/editor.css` |
| Геометрия блоков | `frontend/block-models.js` |
| Предпросмотр схемы | `frontend/schematic3d.js` |
| Предпросмотр склада | `frontend/scene3d.js` |

Не добавляйте сгенерированные текстуры, атласы и иконки Minecraft в Git. Используйте небольшие искусственные схемы с лестницами, заборами, заполненными водой состояниями, несколькими регионами и отрицательными размерами.
