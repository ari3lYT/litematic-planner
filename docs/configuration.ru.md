# Настройка

| Переменная | По умолчанию | Назначение |
| --- | --- | --- |
| `LITEMATIC_HOST` | `127.0.0.1` | Адрес HTTP-сервера |
| `LITEMATIC_PORT` | `8874` | HTTP-порт |
| `LITEMATIC_DB` | `planner.sqlite3` рядом с `app.py` | Постоянная база совместной работы |

Сгенерируйте графические ресурсы через `scripts/prepare_assets.py` и локальный помощник для иконок. Версия клиента для текстур и моделей должна совпадать. Локально создаваемый реестр редактора основан на данных 26.1; конвейер моделей изначально проверялся на Java-клиенте 26.3. Неизвестные состояния и блоки модов могут сохраняться в схеме, даже если для них нет модели или записи каталога.

Для сетевого размещения используйте обратный TLS-прокси с ограничениями размера запроса и времени обработки. Общей учётной записи администратора нет. Обладание ссылкой коллекции даёт доступ к ней. Базы, резервные копии и ссылки с ключами должны оставаться приватными.
