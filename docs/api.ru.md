# HTTP API

Точные поля запросов определены маршрутами `App.do_GET` и `App.do_POST` в `app.py`. Эталонный клиент — браузерные скрипты. Все JSON-ответы используют UTF-8.

| Маршрут | Контракт |
| --- | --- |
| `GET /api/health` | Состояние процесса без содержимого базы |
| `GET /api/catalog` | Каталог материалов |
| `GET /api/editor-catalog` | Каталог редактируемых блоков и координаты сгенерированных иконок |
| `GET /api/state?project=...` | Снимок коллекции с проверкой доступа |
| `POST /api/schematic-preview` | Разбор и предпросмотр загруженной схемы |
| `POST /api/schematic-export` | Применение изменений и выдача `.litematic` |

Редактор принимает multipart-загрузки; структура `FormData` показана в `static/editor.js`. Изменения коллекций сгруппированы по маршрутам в `app.py`. Доступ к коллекции и личность участника проверяются отдельно. Изменения склада передают версию: при устаревшей версии нужно обновить данные, чтобы не затереть чужую работу.

Не публикуйте реальные ссылки коллекций с ключами в примерах, скриншотах или сообщениях об ошибках.
