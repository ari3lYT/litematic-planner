# Отрисовка стандартных блоков

`block-models.js` обрабатывает варианты состояний Java-блоков и правила multipart, родительские модели, псевдонимы текстур, UV граней, повороты, UV lock и оттенки. `schematic3d.js` создаёт экземпляры полученной геометрии для каждого состояния в схеме. Неподдерживаемые модели явно отмечаются в просмотрщике.

Ресурсы в `static/minecraft/` подготовлены из локально установленного клиента Minecraft Java 26.3. Для повторного создания набора моделей и атласа текстур:

```sh
python3 frontend/build-minecraft-assets.py /absolute/path/to/minecraft-client.jar
```

`build-block-icons.js` рисует иконки по той же геометрии. `block-icons.png` и индекс `block-icons.json` создаются локально рядом с набором моделей и исключены из Git. Обычная сборка интерфейса повторно использует эти файлы.

Выполните `npm run build` из `frontend/`, чтобы собрать просмотрщик. `check-models.mjs` проверяет силуэты реальных моделей трассировкой лучей, выбор multipart-компонентов, оттенки граней и особую модель сундука. Ресурсы моделей не выполняют код игры и не меняют NBT схемы.
